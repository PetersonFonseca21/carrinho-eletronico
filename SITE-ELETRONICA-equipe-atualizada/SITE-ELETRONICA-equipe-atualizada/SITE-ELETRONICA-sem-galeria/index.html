CARRO COM ARDUINO

Projeto de eletrônica e programação desenvolvido para demonstrar, na prática, a integração entre microcontrolador, sensores, motores e alimentação elétrica.

Conheça o projetoVer componentes

Sobre o projeto

Uma visão geral do carrinho eletrônico.

O que é?

É um carrinho robótico controlado por um Arduino, utilizando componentes eletrônicos para receber informações, processá-las e controlar o movimento dos motores.

Proposta

Aplicar conhecimentos de programação, eletrônica e automação em um protótipo físico, relacionando teoria e prática em um projeto acadêmico.

Como funciona

O processo pode ser dividido em etapas.

01

Entrada: sensores ou comandos fornecem informações ao sistema.

02

Processamento: o Arduino interpreta os dados e executa a programação.

03

Saída: o circuito aciona os motores e realiza o movimento desejado.

Principais componentes

Elementos utilizados no desenvolvimento do protótipo.

🧠

ESP32

Microcontrolador responsável pelo processamento da lógica do projeto.

⚙️

Motores

Realizam a movimentação das rodas do carrinho.

📡

Sensor

Permite detectar informações do ambiente, conforme a configuração do projeto.

🔋

Alimentação

Fornece energia elétrica para o funcionamento do sistema.

Objetivos

O que o projeto busca demonstrar.

01 — Programação

Aplicar lógica de programação no controle do protótipo.

02 — Eletrônica

Relacionar tensão, corrente, componentes e circuitos ao funcionamento real.

03 — Automação

Integrar entradas, processamento e atuadores em um único sistema.

04 — Trabalho em equipe

Desenvolver uma solução prática de forma colaborativa.
